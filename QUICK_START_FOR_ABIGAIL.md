## 🚀 How to Open & Work in Antigravity (Windows)

1. **Unzip the Folder**:
   - Right-click `AbigailMorra.zip` on your Desktop and select **Extract All...**
   - Place the extracted `AbigailMorra` folder directly on your Desktop.

2. **Open Antigravity**:
   - Open the **Antigravity IDE** on your Windows computer.
   - Click **File** ➔ **Open Folder...** (or press `Ctrl + O`).
   - Select the `AbigailMorra` folder from your Desktop.

3. **Talk to Antigravity**:
   - Antigravity already has full instructions loaded about your website and your aesthetic.
   - You can talk to it in natural English, just like you would to an assistant. For example:
     - *"Hey Antigravity, I just dropped 10 new photos from my Sports shoot into the photos folder. Can you add them as a new coffee table book and push it to the live site?"*
     - *"Can you change the order of the photos in Assignment 01?"*
     - *"Can we make the Gilbert sticker in the blue header spin when clicked?"*
     - *"Can you check that the website is working and push all changes to GitHub?"*
   - Antigravity will make the code changes, test them, and automatically push them to your live website!

## 🌐 How GitHub Sync Works

- Your folder is already connected to your GitHub repository (`https://github.com/itsmcmurdoj/AbigailMorra`).
- **Antigravity will push updates for you automatically** whenever you ask it to make changes.
- If you ever want to push updates manually without using the chat:
  - Simply double-click **`push_to_github.bat`** inside this folder.
- If you ever need to generate a new GitHub API Token:
  - Double-click **`setup_github_token.bat`** and paste the new token.

---

## 💻 Quick Preview (Testing Locally)

- Want to see your website offline without pushing?
  - Double-click **`preview.bat`** inside this folder.
  - It will start a local preview at `http://localhost:8080` in your web browser.
